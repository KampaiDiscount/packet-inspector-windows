# Security reporting

For a suspected vulnerability in Packet Inspector for Windows, use
**[GitHub private vulnerability reporting](https://github.com/KampaiDiscount/packet-inspector-windows/security/advisories/new)**.
Keep exploitable details and sensitive evidence out of public issues.

Include the package version or commit, Windows and Python versions, relevant
Npcap/Wireshark versions, expected and actual behavior, and a minimal synthetic
reproduction where possible. Describe the impact and any applicable capture,
dashboard, or filesystem permissions. Remove real credentials, tokens, account
identifiers, and unrelated network data before attaching logs or captures.

The current published version is **0.1.4+win.1**, a Windows test prerelease.
Reports against that release and the current `main` branch are welcome. Its
recorded validation and deployment-specific acceptance boundaries are described
in [WINDOWS-VALIDATION.md](WINDOWS-VALIDATION.md).

For ordinary installation questions and non-sensitive bugs, use
[GitHub issues](https://github.com/KampaiDiscount/packet-inspector-windows/issues).
See [WINDOWS.md](WINDOWS.md#evidence-and-privacy) for evidence ACLs and local
dashboard access before collecting a reproduction.
